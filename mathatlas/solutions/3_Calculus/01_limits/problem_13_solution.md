# Problem Statement

**Exercise 13: Fundamental Trigonometric Limit.**

Using
$$\lim_{x\to0}\frac{\sin x}{x}=1,$$
compute
$$\lim_{x\to0}\frac{\sin5x}{x},\qquad \lim_{x\to0}\frac{\sin2x}{\sin3x}.$$
In each case, show how you reduce the expression to the fundamental limit.

## Theoretical Background and Concepts

Rewrite using the fundamental limit $\sin t/t\to1$.

## Detailed Step-by-Step Solution

**Step 1 — Identify the method.** Rewrite using the fundamental limit $\sin t/t\to1$.

**Step 2 — Calculate and interpret.** $\frac{\sin5x}{x}=5\frac{\sin5x}{5x}\to5$. Also $\frac{\sin2x}{\sin3x}=\frac23\frac{\sin2x/(2x)}{\sin3x/(3x)}\to\frac23$.

## Verification and Consistency Checks

Each normalized sine quotient tends to 1, so the constants 5 and 2/3 remain.
